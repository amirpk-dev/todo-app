# Todo App

A simple Todo application built with **HTML** and **Vanilla JavaScript**.

This project was created to practice JavaScript fundamentals by building a complete application from scratch instead of only following tutorials.

## Features

* Add new todos
* Mark todos as completed
* Edit todos by double-clicking
* Delete todos
* Automatically save todos using Local Storage
* Add todos by pressing **Enter** or clicking the **Add** button

## Technologies Used

* HTML5
* JavaScript
* Local Storage API

## What I Learned

While building this project, I practiced:

* DOM manipulation
* Event handling
* Arrays and objects
* Creating and updating UI dynamically
* Working with Local Storage
* Organizing JavaScript into reusable functions
